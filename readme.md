## 0.1 摘要
在使用LLM开源模型的过程中，仅仅对 __Prompt Engineer__ 即 __提示词工程__ 上面做功夫必然不能够满足工业领域较为复杂的应用场景。

对于本地开源LLM和本地开源RAG建立向量知识库，本文选择了2024年04月开源的[RagFlow](https://github.com/infiniflow/ragflow)。

<!--more-->
## 0.2 背景依托
>博0阶段横向

+ 为XUST开发自有LLM，并为后续相关横向项目积累经验。
+ 工业大模型的定制化开发，满足其 __可信性、实时性__。
+ 向量库的创建属于 __"重复造轮子"__ 的工作，无非就是
    - 选择一个向量库存储引擎
    - 写一套PDF、Word、Txt文件的解析方法
    - 挂一个本地`Embedding`，并连接
    - 做文本匹配接口
    - 耦合本地LLM和以上创建的知识库
    
    因此没有特殊需求，例如 __定期爬虫__ 等特殊场景（其实开源的RAG框架也陆续支持这些特殊场景的知识工程了），没必要自己写一套。
